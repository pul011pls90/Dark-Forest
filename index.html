Cross-Device Synchronization Readiness

Current Mode: Local-First (Browser Storage v2)
All records use stable UUID-style identifiers, ISO timestamps, idempotent recurring occurrence keys (recurringId + occurrenceDate), and versioned schema envelopes—ready for optional end-to-end or row-level-secured cloud sync without data loss. No cloud backend is connected in this static deployment; use Backup JSON / Restore Backup to move data across devices today, or see SYNC_ARCHITECTURE.md for the full backend specification.
